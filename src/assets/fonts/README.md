# TAN Songbird

Police commerciale (TAN Type Foundry) — non incluse dans le depot.

## Installation

1. Deposer ici le fichier achete, nomme :
   - `TANSongbird.woff2` (ideal), ou `.woff` / `.otf` / `.ttf`
2. Le `@font-face` est deja declare dans `src/index.css` et pointe vers
   `./assets/fonts/TANSongbird.woff2`. Ajuster l'extension si besoin.
3. Rien d'autre a faire : `.footer-wordmark` demande deja "TAN Songbird"
   en premier dans sa pile.

Tant que le fichier est absent, le rendu retombe sur Mouse Memoirs.
